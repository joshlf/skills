# Authorship disclosure: design

This package applies when preparing or revising externally visible prose or Git
commits, including handoffs. Ordinary conversation and private scratch work
need no notice. Its purpose is to disclose material retained agent
contributions accurately, without accumulating redundant drafting-history
labels.

Judge the final retained work, including contributions from earlier agents.
Mechanical copying does not erase authorship; discarded contributions need no
memorial. Preserve contributor identity and applicable prior attribution. Human
approval is not automatically adoption of the prose as the user’s own.

Git commits and separately presented prose have different disclosure units. A
commit’s files and message use one trailer with a qualifier for content-only or
message-only contributions where appropriate. Separately presented prose
normally uses one visible scoped notice, unless a distinct bot identity or
explicit adoption supplies the relevant disclosure. Keeping these cases
distinct prevents a generic notice from misidentifying who contributed what.

An append-only log would preserve drafting history but leave stale or duplicate
notices; unrestricted removal could erase retained contributions. The package
instead permits maintaining disclosures within the authorized edit scope. It
assumes the contribution context and established user identity can be resolved;
it must not invent an address or certification. Reopen the design if a
legitimate handoff cannot preserve accurate attribution, if a rendering path
repeatedly loses a required notice, or if the rules cause duplicate notices for
the same retained contribution. Disclosure does not certify human review or
authorize publication.
