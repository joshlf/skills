# Swarm model refinement: design

This package governs multi-agent conceptual model refinement across theories,
software designs, state machines, schemas, protocols, configuration, and
instructions when high design-space ambiguity, coupled trade-offs,
self-revision, or held-out confirmation isolation justify coordination cost.
Cosmetic shortening, routine implementation of a settled design, neural-network
compression, and bounded single-concept work where single-agent
`model-refinement` suffices are outside its scope. Invoking or installing this
skill grants no authority to start background processes, schedule recurring
jobs, launch unrelated sub-agents, mutate canonical repositories outside
scratch, or execute external publication or deployment actions.

The skill depends on `model-refinement` and fails closed without launching a
refinement swarm when it is unavailable. Before spawning workers, a single
high-capability coordinator selects the smallest adequate scale (`Scale-0`
exit, `Scale-1` lean, or `Scale-2` full), retains contract custody, synthesis,
adjudication, layer diagnosis, rereads, and external action authority, and
optionally composes with separately installed authoring, research, or workflow
packages without requiring unselected dependencies.

Seven epistemic packets and an explicit access matrix isolate blind
confirmation and unanchored review from candidate generation. When blind
confirmation is used, `Steward` authors `Partition 1` upfront (plus reserve
`Partition 2` when multi-pass repair is plausible), and any disclosed case or
shared-body sibling is permanently tagged `exposed-holdout` rather than counted
as unexposed confirmation. Round-1 architects diverge along orthogonal
structural priors (`α`, `β`, `γ`, optional `δ`), and single-pass ephemeral
evaluators judge immutable `snap-<hash>/` snapshots using falsifiable evidence
rather than votes or universal size caps. On hosts with Python 3.8+ CLI and
cross-subagent file handoff, an optional standard-library helper
(`scripts/holdout-seal.py`) stores UTF-8 holdouts behind `0400` `.sealed`
envelopes as a cooperative safeguard against accidental reads; otherwise the
protocol falls back to a private sub-agent vault and records provenance and
exposure honestly.

Each Phase-3 boundary reruns a mandatory context reread, scopes findings to the
active snapshot and owning layer, and selects the first matching transition in
a deterministic six-rung ladder (`T1`–`T6`): bounded blocker stops, budgeted
`Lift → Single Base → Subtract` synthesis, mechanical hygiene or
`Adversary`-corroborated dispute steps, recursive self-revision supersession,
one-critic confirmation on unchanged snapshots, or calibrated local
convergence without mutating the converged deliverable. Structural checks do
not establish multi-domain behavioral effectiveness, cross-family critic gains,
or cost savings; revisit the protocol, scaling defaults, or optional sealing
helper if hosts enforce per-subagent private storage or evidence shows poor
cost-to-rigor trade-offs.
